Inspection Rules

· how guided inspections behave
Not OK requires comment Required
When a driver marks any item "Not OK", a written comment must be entered before they can continue.
Not OK requires photo Required
"Not OK" items must include at least one photo — evidence is tied to the vehicle, driver and timestamp.
Critical item Not OK → Supervisor Review
A safety-critical item marked "Not OK" automatically routes the inspection for supervisor review and blocks the vehicle until cleared.
Enable end-of-day return inspection
Prompt drivers to complete a shorter return inspection when handing the vehicle back at end of shift.
Require GPS on capture
Attach GPS coordinates to each inspection and photo. Off by default while depot connectivity is being verified.
Enable offline mode
Allow drivers to complete inspections without a connection; data syncs automatically once back online.
